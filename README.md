# New York Store

Proyecto frontend de Desarrollo Full Stack II.

## Ejecutar

Requiere Node.js 20.19 o superior.

```sh
npm ci
npm run dev
```

Abrir la dirección que indique la terminal.

## Administrador

Correo: admin@duoc.cl

## Pruebas y compilación

```sh
npm test
npm run build
```

Si el navegador automático no inicia, ejecutar `npm run test:manual` y abrir http://localhost:9876/ en Chrome o Edge. La cobertura se genera en `coverage/html/index.html`.

Los datos se guardan en localStorage. El pago es simulado y las credenciales son de demostración.
